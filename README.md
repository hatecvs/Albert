# My Favorite Movie

**Avengers: Endgame** is one of my favorite movies because of its exciting action, emotional scenes, and amazing storyline.

### Movie Information
- **Title:** Avengers: Endgame
- **Genre:** Action / Science Fiction
- **Year Released:** 2019

I like this movie because it shows the importance of **friendship, teamwork, sacrifice, and courage**.
